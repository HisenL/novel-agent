# Novel Agent

[简体中文](README.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

ローカルの作品ファイルを中心に、小説の構想、場面の計画、執筆、推敲を行うデスクトップ型エージェントです。モデルが提案した変更は、作者が確認して承認した後に正式な原稿へ反映されます。

**0.2.0 は初期リリース**で、Windows x64 向けの実行版とソースコードを提供しています。アプリの画面と詳細ドキュメントは主に簡体字中国語です。README は 4 言語に対応しています。

## ダウンロードして実行（ソースコード不要）

**アプリを使う場合は [最新リリース](https://github.com/HisenL/novel-agent/releases/latest) の Assets から実行版を選んでください。Source code は実行版ではありません。**

1. 推奨：[Windows x64 ポータブル EXE](https://github.com/HisenL/novel-agent/releases/download/v0.2.0/Novel-Agent-0.2.0-windows-x64.exe) をダウンロードし、ダブルクリックします。Node.js、pnpm、Git、管理者権限は不要です。
2. 代替：[Windows x64 ZIP](https://github.com/HisenL/novel-agent/releases/download/v0.2.0/Novel-Agent-0.2.0-windows-x64.zip) を**すべて展開**し、`Novel Agent.exe` を起動します。EXE だけを移動したり、ZIP 内で実行したりしないでください。
3. アプリで自分のモデルサービスを設定して接続をテストし、作品を作成・読み込みします。API キーやローカルモデルは付属しません。オンラインのモデル呼び出しには接続と料金が必要になる場合があります。

アプリ設定は `%APPDATA%\Novel Agent`、原稿とタスク履歴は選択した作品フォルダーに保存されます。更新時は保存して旧版を終了し、新版を起動してください。設定や作品を削除する必要はありません。ソース版の設定は自動移行しないため、モデルを再設定して既存作品を開いてください。

本版はコード署名がなく、Windows が発行元不明と表示する場合があります。本リポジトリの Releases からダウンロードし、`SHA256SUMS.txt` と照合してください。システムの保護機能を無効にしないでください。[リリースノート](docs/releases/0.2.0.md)も参照してください。

## 主な機能

- ローカル作品の作成・読み込み・インポート。Markdown 原稿と YAML の創作方針を編集できます。
- あらすじ、場面計画、人物、場所、時系列、伏線を文書として管理します。
- エージェントが読み取り、検索、計画、変更提案のツールを選択し、複数回のモデル呼び出しで作業を進めます。進行状況を確認できます。
- 読み取り専用の相談、変更提案による共作、対象ファイルを限定した一括提案を利用できます。
- 場面計画、会話の推敲、整合性チェックの組み込み指示を確認できます。
- 提案の差分確認、承認、却下、手動調整、フィードバックによる再作成に対応。選択範囲や一意に一致する原文を変更できます。
- 不変のリビジョン履歴を保存し、逆変更の提案で取り消します。外部編集との競合も検出します。
- セッションと未承認の提案を保存し、作品を開き直して手動で作業を再開できます。
- Markdown/YAML フォルダーをプレビュー後にコピーし、保存済みの内容を ZIP に出力します。

## ソースコードから起動

Git、Node.js 22 以降、pnpm 11.8.0 を用意し、プロジェクトのルートで実行してください。

```powershell
pnpm install --frozen-lockfile
pnpm desktop:prepare
pnpm desktop:build
pnpm desktop:start
```

依存関係のインストール時に Electron 本体がダウンロードされなかった場合は、準備とビルドの前に `node apps/desktop/node_modules/electron/install.js` を実行してください。

`pnpm desktop:start` は準備済みのローカルビルドを使用し、起動ごとに依存関係をダウンロードしません。ソースコードが不要な方は、上記の実行版を利用してください。

## 執筆を始める

1. モデル設定で接続先、プロトコル、モデル名、API キーを入力し、保存して接続をテストします。
2. 「新建 / 导入作品」で作品フォルダーを選び、作品管理から創作方針を編集します。
3. 右側に「創作方針と現在の章を読み、場面を計画して冒頭を提案して」などの依頼を入力します。
4. 実行状況と差分を確認し、提案を承認するか、却下して修正意見を伝えます。

モデルサービスには関数ツール呼び出しへの対応が必要です。Responses または Chat Completions を明示的に選択し、接続テストと実際のツール呼び出しで接続先とモデルの互換性を確認してください。デモモデルへの自動切り替えは行いません。

## 作品データ・認証情報・料金

- 原稿、設定、セッション、提案はローカルに保存されます。外部モデルを使う場合、関連する作品内容が設定したサービスへ送信され、そのサービスのデータ取り扱い方針が適用されます。
- API キーは Electron の OS に基づく安全なストレージで暗号化します。原稿、会話、公開の不具合報告にキーを書かないでください。
- 接続テスト、執筆、作業再開には料金が発生する場合があります。ターンごとの呼び出し上限、トークン数、任意の単価による概算を表示します。料金不明は無料を意味しません。
- 接続失敗後に自動再送しません。失敗・中断した呼び出しも課金済みの場合があります。

## 現在の制限

- 実行版は現在 Windows x64 のみで、コード署名はありません。macOS/Linux のデスクトップ版は同等の検証を完了していません。
- 未保存の原稿がクラッシュ後に復元される保証はありません。こまめに保存し、作品フォルダーをバックアップしてください。
- ZIP は保存済み原稿と設定のみを含みます。タスク履歴、未承認提案、認証情報を含む完全バックアップではありません。
- インポートは深さ 8 階層、走査対象 2,000 項目、候補 50 ファイル、各ファイル最大 1 MiB までです。
- コンテキストと検索範囲には上限があり、長編向けの階層的記憶は未実装です。生成文と整合性レポートは作者が確認してください。
- DOCX/EPUB、クラウド同期、コミュニティ製実行プラグイン、小説全体のワンクリック完成には対応していません。
