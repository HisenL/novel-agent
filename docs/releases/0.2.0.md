# Windows 免安装运行版 / Windows ready-to-run edition

本版首次提供自带运行环境的 Windows x64 程序，不需要安装 Node.js、pnpm 或下载源码。

## 直接运行

1. 在本页 **Assets** 下载 `Novel-Agent-0.2.0-windows-x64.exe`，双击运行，无需管理员权限。
2. 或下载 `Novel-Agent-0.2.0-windows-x64.zip`，完整解压后双击文件夹内的 `Novel Agent.exe`。不要只取出 EXE，也不要在 ZIP 内直接运行。
3. 打开客户端后配置自己的模型服务，保存并测试连接，再新建或打开作品。模型调用仍需网络及有效账户，可能收费。

`Source code (zip)` / `Source code (tar.gz)` 是开发者源码，不是可运行客户端。

## 数据与更新

- 模型设置及最近作品记录保存在 `%APPDATA%\Novel Agent`，不在 EXE 的临时解压目录中。
- 作品正文和任务历史位于自己选择的作品文件夹。请定期备份整个作品文件夹；导出 ZIP 不等于完整备份。
- 程序没有内置模型密钥，不会自动导入开发版配置。旧源码用户需在新客户端重新配置模型，再打开原作品。
- 后续升级：保存并关闭旧程序，下载新版再运行；不需要删除设置或作品。没有自动安装更新。

## 完整性与限制

- `SHA256SUMS.txt` 提供 EXE 和 ZIP 的校验和。PowerShell 可用 `Get-FileHash .\Novel-Agent-0.2.0-windows-x64.exe -Algorithm SHA256` 对照。
- 本版**尚未代码签名**，Windows 可能提示未知发布者。只从本仓库 Releases 下载，核对来源与校验和；不要关闭安全防护。若系统阻止运行，请保留提示并反馈。
- 仅提供 Windows x64 二进制；不是 Windows ARM 原生版。未完成独立安全审计。创作功能和已知限制见 README。

## English

Download the `.exe` under **Assets** and run it, or fully extract the `.zip` and launch `Novel Agent.exe` without moving it away from its companion files. No source checkout, Node.js or pnpm is required. The automatically generated **Source code** archives are not runnable distributions.

Configure your own model endpoint and API key in the client. Online model calls may incur charges. Settings persist in `%APPDATA%\Novel Agent`; stories and history remain in your chosen project folder. The executable is unsigned: verify the official source and `SHA256SUMS.txt`, and do not disable Windows security protections. This is an early Windows x64 release with no automatic updates.
