## 启动与模型

按[开发与验证](development.md)准备源码后，双击根目录 `启动小说智能体.cmd`，或运行 `pnpm desktop:start`。首次向导之后仍可从“使用指南”打开。

在“模型设置”填写服务地址、协议、模型名和 API Key。模型须支持函数工具调用，OpenAI 官方地址使用 Responses，其他服务按实际能力选择。“保存并测试连接”会产生可能收费的请求，密钥只填设置页。

使用外部模型时，相关稿件发送到配置的地址；编辑本地文件无需模型连接。可填写输入、输出美元／百万 Token 单价，按返回用量估算。未知费用不等于免费，修改单价不重算历史。

## 作品与文件

点击“新建 / 导入作品”选择独立文件夹，在“作品管理”→“作品设置表单”填写名称、类型、视角、人物目标、世界规则、风格与禁区。中间编辑器使用保存按钮或 Ctrl+S 保存。

已有作品选择根目录。误选空文件夹时，可在“作品管理”确认初始化；失败切换保留原作品。运行中的任务须先暂停再切换。更改作品名不会更改磁盘文件夹名；目前无客户端内的作品搬迁或删除功能。

| 内容     | 相对路径示例                   |
| -------- | ------------------------------ |
| 正文     | `manuscript/main/chapter-2.md` |
| 场景计划 | `outline/chapter-2.md`         |
| 人物     | `canon/characters/主角.md`     |
| 时间线   | `canon/timeline.md`            |
| 伏笔     | `canon/foreshadowing.md`       |

作品树的添加按钮可创建上述类型的模板。导入时先核对来源与目标，确认后 Markdown 复制到 `manuscript/imported/`，YAML 复制到 `canon/imported/`，保留相对目录。来源不变，已有目标跳过；复制后编辑副本，来源不自动同步。

导入最多扫描八层子目录、2,000 个条目，预览 50 个文件，每个最多 1 MiB，要求 UTF-8。隐藏目录、链接、受管作品目录不作为新来源。根目录 `story.yaml` 和 `NOVEL.md` 保留原用途。部分导入失败可重试，已有目标仍不覆盖。

## 创作任务

- **探索**：只读讨论、规划，不生成候选。
- **共创**：按需使用工具，生成待审候选。
- **批量候选**：限定 1–8 个已保存文件，确认调用上限，逐项审阅；不能同时使用只读或选区。

先讨论：

> 读取创作约定和当前章节，提出三个开场方向，说明主角动机。先讨论，不生成候选。

再写作：

> 采用第二个方向，先列场景计划，再生成开场约 600 字的候选，遵守创作约定。

内置场景规划、对白润色、连续性审稿可展开查看规则；审稿强制只读。选择技能不调用模型，旧轮规则不会被改写。“新任务”清除旧技能、文件范围和选区。暂停、调用上限、文件冲突或服务错误会停止执行。继续任务可能再次收费，创作分岔识别与稿件质量仍需作者核对。

## 审阅与撤销

在“修改对比”接受候选才发布；拒绝保留正文。可手动调整后接受，或“准备重做要求”再补充意见发送；重做不自动处理旧候选。

局部改写先选中文字并确认选区提示，也可给出唯一、连续的原文精确替换。保存正文后再审阅候选，基线过期或外部编辑时拒绝覆盖。“版本历史”→“撤销这次修改”生成反向候选，仍需接受，并留下新修订。

外部编辑后先另行保留未保存文字，再“重新读取文件”。

## 恢复与导出

重开原作品可查看会话、候选与状态；历史支持搜索和筛选。“继续任务（将调用模型）”可能收费，恢复联网或重开窗口不会自动重发。历史技能不匹配会在调用前停止，可查看新规则后提交新一轮要求。

光标位置可恢复，未保存正文不保证崩溃恢复。关闭前请保存，退出后另行备份作品文件夹。

ZIP 只含已保存正文和设定，不含历史、候选和密钥，不是完整备份。ZIP 先解压，再打开或导入。

## 故障反馈

连接错误时核对地址、协议、模型权限、网络和代理；失败调用也可能已计费。输出不完整时检查输出上限与任务范围。执行进程退出时先复制保留未保存文字，再重开原作品。

报告版本、系统、操作步骤和错误文字，移除密钥与私人稿件。安全问题按[安全政策](../SECURITY.md)私下反馈。
