# 安全边界与威胁模型

[安全报告](../../SECURITY.md) · [架构](../architecture.md)

## 目标与边界

保护稿件、身份、凭据与历史；阻止静默覆盖；保留事件和审批因果；在取消、失败、外部编辑及发布中断后停止或恢复。

作者批准修改，模型、作品文本和工具参数是不可信输入。Renderer 请求操作，Kernel 管理工具、范围和发布，Main 管理文件对话框与加密密钥。外部模型按服务商政策处理收到的内容。

| 威胁           | 当前控制                                | 剩余边界                       |
| -------------- | --------------------------------------- | ------------------------------ |
| 提示注入与越权 | 工具白名单、只读、精确能力、受管路径    | 误导建议需作者核对             |
| 静默覆盖       | 基线 hash、审批、冲突停止、不可变修订   | 不自动合并语义冲突             |
| 路径逃逸       | 路径、Windows 名称、大小写、链接检查    | 无恶意本地进程的 OS 级隔离     |
| 事件缺口与重复 | SQLite 约束、事务、严格回放             | 无签名或本机管理员防篡改保证   |
| 发布中断       | 同目录临时文件、落盘、事件对账          | 未覆盖所有硬件与断电组合       |
| 凭据泄漏       | 安全存储、私有通道、脱敏错误            | 作者不应把秘密写入正文或消息   |
| 外部发送       | 显式端点、HTTPS、重定向拒绝、有限上下文 | 相关稿件仍会发送给服务商       |
| 费用失控       | 调用、输出、超时上限，手动继续          | 无完整货币硬预算，失败可能收费 |
| 第三方代码     | 无社区可执行宿主                        | Utility Process 不是代码沙箱   |

## 数据保护

账本、候选和回复可能含稿件，不要公开上传运行目录或私人诊断数据。退出后备份作品文件夹；ZIP 不包含完整历史，未保存文字不保证崩溃恢复。

依赖用锁文件固定。源码发布和测试不代表独立安全审计。安全问题应私下报告，不附真实密钥和私人稿件。
