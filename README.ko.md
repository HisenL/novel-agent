# Novel Agent

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

로컬 작품 파일을 중심으로 소설의 구상, 장면 계획, 집필과 검토를 진행하는 데스크톱 에이전트입니다. 모델이 제안한 변경은 작가가 검토하고 승인한 뒤 정식 원고에 반영됩니다.

**0.2.0은 초기 버전**이며 Windows x64 실행 프로그램과 소스 코드를 제공합니다. 앱 인터페이스와 상세 문서는 주로 중국어 간체로 제공되며 README는 네 가지 언어를 지원합니다.

## 다운로드 후 실행 (소스 코드 불필요)

**프로그램만 사용하려면 [최신 릴리스](https://github.com/HisenL/novel-agent/releases/latest)의 Assets에서 실행 파일을 받으세요. Source code는 실행 프로그램이 아닙니다.**

1. 권장: [Windows x64 무설치 EXE](https://github.com/HisenL/novel-agent/releases/download/v0.2.0/Novel-Agent-0.2.0-windows-x64.exe)를 다운로드하고 더블 클릭합니다. Node.js, pnpm, Git이나 관리자 권한이 필요하지 않습니다.
2. 대안: [Windows x64 ZIP](https://github.com/HisenL/novel-agent/releases/download/v0.2.0/Novel-Agent-0.2.0-windows-x64.zip)을 **전체 압축 해제**한 뒤 `Novel Agent.exe`를 실행합니다. EXE만 옮기거나 ZIP 안에서 실행하지 마세요.
3. 클라이언트에서 본인의 모델 서비스를 설정하고 연결을 테스트한 뒤 작품을 만들거나 엽니다. API 키와 로컬 모델은 포함되지 않습니다. 온라인 모델 호출에는 네트워크가 필요하며 요금이 발생할 수 있습니다.

클라이언트 설정은 `%APPDATA%\Novel Agent`에, 원고와 작업 기록은 선택한 작품 폴더에 저장됩니다. 업데이트할 때 저장 후 이전 프로그램을 닫고 새 버전을 실행하세요. 설정이나 작품을 지울 필요는 없습니다. 소스 버전 설정은 자동으로 가져오지 않으므로 모델을 다시 설정한 후 기존 작품을 여세요.

현재 코드 서명이 없어 Windows에서 알 수 없는 게시자로 표시할 수 있습니다. 이 저장소의 Releases에서만 다운로드하고 `SHA256SUMS.txt`를 확인하세요. 시스템 보안 기능을 끄지 마세요. [릴리스 안내](docs/releases/0.2.0.md)를 참고하세요.

## 기능

- 로컬 작품 생성·열기·가져오기, Markdown 원고 편집, YAML 창작 원칙 관리.
- 개요, 장면 계획, 인물, 장소, 시간선과 복선을 문서로 정리.
- 에이전트가 읽기, 검색, 계획 및 변경 제안 도구를 선택하고 여러 모델 호출에 걸쳐 작업하며 진행 상황을 표시.
- 읽기 전용 탐색, 제안 기반 공동 집필, 파일 범위를 지정하는 일괄 제안 모드.
- 내장된 장면 계획, 대화 다듬기, 연속성 검토 지침 확인.
- 제안 비교·승인·거절·직접 조정·의견에 따른 재작성, 선택 영역 및 유일하게 일치하는 원문 수정.
- 변경 불가능한 리비전 기록, 역방향 제안으로 되돌리기, 외부 편집 충돌 감지.
- 세션과 검토 대기 제안을 저장하고 작품을 다시 열어 수동으로 작업 재개.
- Markdown/YAML 폴더를 미리 본 뒤 복사하여 가져오고, 저장된 내용을 ZIP으로 내보내기.

## 소스 코드로 실행

Git, Node.js 22 이상, pnpm 11.8.0을 준비한 뒤 프로젝트 루트에서 실행합니다.

```powershell
pnpm install --frozen-lockfile
pnpm desktop:prepare
pnpm desktop:build
pnpm desktop:start
```

의존성 설치 중 Electron 실행 파일이 다운로드되지 않았다면 준비와 빌드 전에 `node apps/desktop/node_modules/electron/install.js`를 실행하세요.

`pnpm desktop:start`는 준비된 로컬 빌드를 사용하며 실행할 때마다 의존성을 다운로드하지 않습니다. 소스 코드가 필요 없는 사용자는 위의 실행 프로그램을 이용하세요.

## 집필 시작

1. 모델 설정에 서비스 주소, 프로토콜, 모델 이름과 API 키를 입력하고 저장한 뒤 연결을 테스트합니다.
2. “新建 / 导入作品”에서 작품 폴더를 선택하고 작품 관리에서 창작 원칙을 작성합니다.
3. 오른쪽에 “창작 원칙과 현재 장을 읽고 장면을 계획한 뒤 도입부를 제안해 줘”와 같은 작업을 입력합니다.
4. 실행 상황과 변경 내용을 확인하고 제안을 승인하거나, 거절하고 수정 의견을 전달합니다.

서비스는 함수 도구 호출을 지원해야 하며 Responses 또는 Chat Completions 프로토콜을 명시적으로 선택해야 합니다. 연결 테스트와 실제 도구 호출을 통해 주소와 모델의 호환성을 확인하세요. 데모 모델로 자동 전환하지 않습니다.

## 콘텐츠, 인증 정보 및 비용

- 원고, 설정, 세션과 제안은 로컬에 저장됩니다. 외부 모델 사용 시 관련 작품 내용은 설정한 서비스로 전송되며 해당 서비스의 데이터 정책이 적용됩니다.
- API 키는 Electron의 운영체제 기반 보안 저장소를 사용해 암호화합니다. 원고, 대화 또는 공개 이슈에 키를 넣지 마세요.
- 연결 테스트, 집필과 작업 재개에는 요금이 부과될 수 있습니다. 턴별 호출 한도, 토큰 사용량과 선택적인 단가 기반 예상 비용을 제공합니다. 비용을 모른다는 것이 무료라는 뜻은 아닙니다.
- 연결 실패 후 요청을 자동 재전송하지 않습니다. 실패하거나 중단된 요청도 이미 과금되었을 수 있습니다.

## 현재 제한 사항

- 현재 실행 파일은 Windows x64만 지원하며 코드 서명이 없습니다. macOS/Linux 데스크톱은 같은 수준의 검증을 완료하지 않았습니다.
- 저장하지 않은 원고는 충돌 후 복구되지 않을 수 있습니다. 자주 저장하고 작품 폴더를 백업하세요.
- ZIP에는 저장된 원고와 설정만 포함됩니다. 작업 기록, 대기 중인 제안과 인증 정보를 포함하는 전체 백업이 아닙니다.
- 가져오기는 하위 폴더 8단계, 검사 항목 2,000개, 후보 파일 50개로 제한되며 파일당 최대 1 MiB입니다.
- 컨텍스트와 검색 범위에는 한도가 있으며 장편용 계층적 기억은 아직 없습니다. 생성 원고와 연속성 보고서는 작가가 확인해야 합니다.
- DOCX/EPUB, 클라우드 동기화, 실행 가능한 커뮤니티 플러그인 및 한 번의 클릭으로 소설 전체를 완성하는 기능은 제공하지 않습니다.
